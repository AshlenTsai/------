# 模型发布清单

`catalog.json` 是人工核对的主要命名版本清单，核对截止日为 2026-10-20。每组包含品牌、首次公开年份、模型名称及一手来源；生成时展开为逐模型记录，按品牌和年份求和，不从安全报告数反推模型数。

- 统计公开发布的命名生成式模型版本，包含公开预览和对外受限访问版本；不含内部研究模型、嵌入模型、审核分类器及单纯产品功能更新。
- 不拆参数规模、量化、Base/Instruct、上下文长度及日期快照；独立命名的专业版本分别计数。API 别名、同名预览转正式版和纯推理服务提速不重复计数。
- Meta 范围为 Llama、Code Llama、Muse；Gemini 范围为 Gemini 及 Nano Banana 别名，不包含 Google 的其他模型品牌。
- 模型首发年份与报告公开年份独立。例如，Gemini 2.0 Flash 的首次公开预览属于 2024 年，即使其模型卡收录在 2025 年，也不改变模型首发年份。
- Qwen3.5 的尺寸变体与 Plus 对应版本、Qwen3.6 的尺寸变体与 Plus 对应版本、Qwen3.8 的尺寸变体与 Max 对应版本均按各自主版本合并。Nano Banana 与对应 Gemini Image 名称不重复计数。
- 清单未穷尽全部历史版本，数量是已核实下限。0 表示该年未收录可核实的命名版本，不能解释成从未发布模型；报告数与模型数不能直接计算披露率。

`download-log.json` 记录一手来源的下载状态及本地文本位置。部分站点直接下载失败，但可以通过联网阅读工具核对，使用独立的 `verification` 字段说明；下载失败状态仍保留。网页更新日期、模型卡修订日期和仓库上传日期不能自动作为模型首发日期。

更新清单后，在项目根目录执行：

```powershell
python scripts/collect_safety_assessments.py --assemble
```
