通过 Kimi API，你可以调用 Kimi K3、K2 系列大模型。平台提供 OpenAI 兼容的
Responses API
和 Anthropic 兼容的
Messages API
。创建 API Key、选择模型并配置
base_url
后，即可直接通过 HTTP 发送请求，或使用 OpenAI SDK、Anthropic SDK 发起调用。
Kimi K3 模型
已正式发布。它是 Kimi 迄今能力最强的模型，支持 1M token 上下文与视觉理解，适合
Kimi Code
、
Codex
、
Claude Code
等编程 Agent 场景，以及知识工作与深度推理场景。加入
Kimi 开发者交流群
，let’s build with kimi!
​
开始使用
1
获取 API Key
访问
Kimi API 开放平台
，登录后进入
API Keys
页面创建并复制 API Key。
请妥善保管你的 API Key，不要泄露给他人，也不要直接硬编码在代码中。建议使用环境变量保存：
export
MOONSHOT_API_KEY
=
"你的_KIMI_API_KEY"
Kimi API 开放平台
登录开放平台，进入控制台、开发工作台和用户中心。
API Keys
创建、复制和管理用于 API 调用的密钥。
2
选择模型
作为快速开始入口，建议优先从 Kimi K3 开始；也可以根据场景选择 Kimi K2.7 Code 或 Kimi K2.6。
Kimi K3
Kimi K3 是面向长程编程与端到端知识工作的旗舰模型——2.8 万亿参数、1M token 上下文，综合智能达到领先水平。
Kimi K2.7 Code
面向代码场景的 Coding 模型，支持 256K 上下文窗口、文本/图片/视频输入和思考模式。如需更高输出速度，可选择
kimi-k2.7-code-highspeed
。
Kimi K2.6
综合能力强，支持 256K 上下文窗口、文本/图片/视频输入、思考与非思考模式，适合通用对话、Agent 任务、视觉理解和复杂推理。
不确定如何选择时，默认从
kimi-k3
开始。如果你主要做代码生成、代码修改或编程 Agent 且追求更高输出速度，可以选择
kimi-k2.7-code-highspeed
。
3
选择调用方式
Kimi API 兼容 OpenAI 与 Anthropic API 格式，你可以根据项目技术栈选择最合适的接入方式。
Chat Completions API
OpenAI 兼容格式，支持 OpenAI SDK 与任意语言 HTTP 接入。
Responses API
OpenAI 兼容格式，生成文本/JSON 输出或调用函数工具。
Messages API
Anthropic 兼容格式，适合 Anthropic SDK、Claude Code 等工具接入。
开发工作台
无需写代码，快速测试提示词、模型效果和业务样例。

探索更多功能
流式输出
启用
stream
，让回复边生成边返回，适合聊天、代码生成和长文本输出场景。
多轮对话
通过维护
messages
列表实现上下文记忆，让模型记住对话历史。
多模态输入
Kimi K3、Kimi K2.7 Code 和 Kimi K2.6 均支持文本、图片与视频输入。
工具调用
让模型调用外部函数或 API，实现 Agent 任务、联网搜索和复杂工作流。
JSON Mode
强制模型输出合法 JSON，方便结构化数据提取和下游系统对接。
思考模型
使用思考能力处理复杂推理、多步工具调用和 Agent 任务。
